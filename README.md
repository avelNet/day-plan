# day-plan

Режим дня в Telegram: утром — план на день (режим, пары из журнала Top Academy, проект, японский, еда, погода), дальше — напоминание перед каждым блоком.

Репозиторий публичный, чтобы GitHub Actions не тратили лимит минут. Токены и пароли — только в Secrets, в лог ничего личного не пишется.

## Запуск

cron-job.org дёргает workflow «Режим дня» (`workflow_dispatch`) в :00 и :30 с 06:00 до 22:30 по Новосибирску. Все блоки плана стоят на получасовой сетке, поэтому каждое напоминание приходит к своему запуску. План строится один раз за день и хранится в кэше Actions.

Если журнал не ответил, план приходит без пар, а бот пробует снова на каждом запуске и присылает «Обновлённый план», как только получится. Вручную: Actions → «Режим дня» → Run workflow → галочка «Перестроить и прислать план на сегодня заново».

## Настройка

**Secrets:** `TG_TOKEN`, `TG_CHAT_ID`, `JOURNAL_LOGIN`, `JOURNAL_PASSWORD`.

**Variables** (всё необязательно):

| Переменная | По умолчанию | Что это |
| --- | --- | --- |
| `WAKE` | `06:30` | Подъём |
| `SLEEP` | `23:00` | Отбой |
| `COMMUTE_MIN` | `40` | Дорога до колледжа, минут |
| `JP_MIN` | `180` | Японский в день (активно), минут |
| `PROJECT_MAX_MIN` | `300` | Потолок на проект в день, остальное — свободное время |
| `PROJECT_NAME` | `Проект` | Название проекта в плане |
| `PROJECT_DEADLINE` | `2027-01-15` | Дедлайн для обратного отсчёта |
| `LAT`, `LON` | Москва | Координаты для погоды |
