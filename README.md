# day-plan

Режим дня и ассистент в Telegram на Cloudflare Workers — бесплатно и без своего сервера.

- **В момент подъёма** — план на день: пары из журнала Top Academy, пробежка, завтрак, проект, японский, обед, ужин, погода.
- **За 5 минут до каждого блока** — напоминание.
- **Чат с нейросетью** прямо в боте: отвечает на вопросы, меняет план на сегодня («перенеси японский на вечер», «я заболел, облегчи день»), запоминает режим на будущее («по выходным встаю в 9», «в среду подъём в 8», «японского 2 часа в день») и работает репетитором японского по программе до JLPT N4.

Команды: `/plan` — план на сегодня, `/replan` — перестроить (подтянуть пары), `/settings` — режим по дням, `/reset` — забыть историю чата, `/help`.

## Как устроено

`worker/src/index.js` — весь бот. Cron Cloudflare срабатывает раз в минуту, Telegram присылает сообщения через webhook. План дня и история чата хранятся в Cloudflare KV. Нейросеть — Workers AI (Qwen3 30B, запасная — Llama 3.3 70B; бесплатно ~10 000 «нейронов» в день), запасной вариант — бесплатные модели OpenRouter, если задан `OPENROUTER_API_KEY`.

Деплой — workflow «Деплой ассистента» при каждом пуше в `worker/`: сам создаёт KV, выкладывает воркер, передаёт секреты и подключает webhook бота.

## Настройка

**Secrets** (Settings → Secrets and variables → Actions):

| Секрет | Что это |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | API-токен Cloudflare по шаблону «Edit Cloudflare Workers» |
| `CLOUDFLARE_ACCOUNT_ID` | ID аккаунта Cloudflare |
| `TG_TOKEN`, `TG_CHAT_ID` | Токен бота и id твоего чата |
| `JOURNAL_LOGIN`, `JOURNAL_PASSWORD` | Вход в журнал |
| `OPENROUTER_API_KEY` | Необязательно: запасная нейросеть |

**Variables** (всё необязательно; значения по умолчанию — режим, заданный в чате, их перекрывает):

| Переменная | По умолчанию | Что это |
| --- | --- | --- |
| `WAKE` | `06:30` | Подъём |
| `SLEEP` | `23:00` | Отбой |
| `COMMUTE_MIN` | `40` | Дорога до колледжа, минут |
| `JP_MIN` | `180` | Японский в день (активно), минут |
| `PROJECT_MAX_MIN` | `300` | Потолок на проект в день, остальное — свободное время |
| `PROJECT_NAME` | `Проект` | Название проекта |
| `PROJECT_DEADLINE` | `2027-01-15` | Дедлайн для обратного отсчёта |
| `LAT`, `LON` | Новосибирск | Координаты для погоды |
| `LLM_MODEL` | `@cf/qwen/qwen3-30b-a3b-fp8,@cf/meta/llama-3.3-70b-instruct-fp8-fast` | Модели Workers AI через запятую, по порядку |

После изменения переменных перезапусти «Деплой ассистента» вручную.

## Старая версия

`day.py` и workflow «Режим дня» — прежняя версия на GitHub Actions + cron-job.org. Когда воркер заработает, отключи задачу в cron-job.org, иначе план будет приходить дважды.
